# Katas do experimento

Os seis exercícios deste diretório foram criados especificamente para o Lab02.
Por isso, os nomes, enunciados e regras não apontam para problemas públicos
conhecidos, reduzindo a probabilidade de uma solução memorizada pelo assistente
de IA.

Cada diretório contém:

- `README.md`: enunciado entregue ao participante;
- `solution.py`: solução de referência usada para validar os testes;
- `test_solution.py`: testes automatizados de aceitação.

Antes de cada trial, copie a assinatura de `solution.py` para um diretório de
trabalho e remova a implementação de referência. Os testes devem permanecer
inalterados.

Execute todos os testes com:

```bash
python -m pytest katas
```
